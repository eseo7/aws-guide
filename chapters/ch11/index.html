01

요금이 새는 대표 지점 7가지

AWS를 쓰다 보면 잊어버린 리소스에서 조용히 비용이 나갑니다. 처음 배울 때 많이 겪는 패턴을 정리했습니다.

서비스함정확인 방법
탄력적 IP 인스턴스 없이 방치 → 시간당 과금 EC2 → 탄력적 IP → 연결 안 된 것 릴리스
EBS 볼륨 인스턴스 종료 후 볼륨이 남음 EC2 → 볼륨 → available 상태 삭제
RDS 중지 후 7일이면 자동 재시작 학습 후 삭제만이 답
NAT Gateway 삭제 안 하면 시간당 $0.059 계속 VPC → NAT Gateway → 삭제
로드 밸런서 인스턴스 없어도 ALB 자체 과금 EC2 → 로드 밸런서 목록 확인
스냅샷·AMI 인스턴스 삭제해도 스냅샷 남음 EC2 → 스냅샷·AMI 탭 직접 확인
호스팅 영역 월 $0.50 고정. 도메인 없어도 청구 Route 53 → 호스팅 영역 목록 확인
🌐
다른 리전도 확인하세요
실수로 도쿄나 버지니아에 만든 리소스가 남아 있을 수 있습니다. 콘솔 우측 상단 리전 드롭다운을 바꿔가며 확인하거나, AWS 리소스 탐색기(Resource Explorer)를 활성화하면 전체 리전을 한 번에 볼 수 있습니다.
02

AWS Budgets — 예산 알림 설정

예산을 설정하면 월 사용량이 임계값에 도달할 때 이메일로 알려줍니다. 이미 CH01에서 $1 예산을 설정했다면 이 챕터에서 더 세밀하게 조정합니다.

권장 예산 구성

예산 이름금액알림 시점
월별 전체 예산$5 (학습 중)실제 85%, 실제 100%, 예측 100%
EC2 예산$2실제 80%
RDS 예산$1실제 80%
  1. Billing → Budgets → 예산 생성
  2. 예산 유형: 비용 예산
  3. 금액 및 기간: 월별 $5
  4. 알림: 실제 비용 85% → 이메일 수신
  5. 알림 추가: 실제 비용 100%, 예측 비용 100%
03

Cost Explorer — 비용 분석

Cost Explorer는 서비스별·리전별·태그별로 비용을 시각화합니다. "지난달 어디서 제일 많이 썼지?"를 파악하는 도구입니다.

📊 Cost Explorer 활용 팁
서비스별 분류

EC2, RDS, NAT Gateway 중 어디서 제일 많이 나오는지 확인. NAT Gateway가 의외로 크게 잡힐 수 있음

리전별 분류

서울 외 다른 리전에 비용이 잡히면 잊어버린 리소스가 있다는 신호

비용 할당 태그

리소스에 태그를 붙이면 Cost Explorer에서 프로젝트별·환경별로 비용을 분리해서 볼 수 있습니다.

🏷 태그 예시
# EC2·RDS·ALB 등 리소스 생성 시 태그 추가
Project: parnas-rewards
Environment: prod
Owner: iseo

# Billing → 비용 할당 태그에서 태그 활성화 (24시간 후 반영)
04

Trusted Advisor — 절약 포인트 자동 감지

Trusted Advisor는 AWS가 자동으로 계정을 스캔해서 비용 절약, 보안 개선, 성능 향상 포인트를 알려주는 서비스입니다.

카테고리체크 항목 예시
비용 최적화사용률 낮은 EC2 인스턴스 · 연결 안 된 탄력적 IP · 유휴 로드 밸런서
보안MFA 미설정 루트 계정 · 0.0.0.0/0으로 열린 SSH 포트 · 공개된 S3 버킷
성능EC2 배치 그룹 활용 여부
내결함성RDS Multi-AZ 미사용 · 단일 AZ EC2
💡
무료 플랜에서도 핵심 보안 체크는 사용 가능합니다
Trusted Advisor 전체 기능은 Business/Enterprise Support 플랜이지만, 보안 관련 핵심 체크(MFA, 공개 S3, 열린 포트 등) 7가지는 무료입니다.
05

월간 점검 루틴 — 10분으로 끝내기

📅
매월 1일, 10분 루틴
  1. Billing → 청구서: 지난달 청구 금액 확인. 예상보다 크면 Cost Explorer로 원인 파악
  2. Cost Explorer: 서비스별 top 3 확인. 이상한 리전에 비용이 잡히면 즉시 확인
  3. EC2 → 인스턴스: running 상태인 인스턴스 목록. 학습용 서버가 남아 있으면 종료
  4. EC2 → 볼륨: available 상태 볼륨 삭제
  5. EC2 → 탄력적 IP: 연결 안 된 IP 릴리스
  6. RDS → 데이터베이스: 실행 중인 DB 확인. 학습용이면 삭제
  7. VPC → NAT Gateway: available 상태면 삭제
  8. Route 53 → 호스팅 영역: 사용 안 하는 호스팅 영역 삭제
  9. 다른 리전 확인: 리전 드롭다운을 도쿄·버지니아로 바꿔서 위 항목 재확인
  10. Trusted Advisor → 보안: 빨간 항목 해결
